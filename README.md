# Power BI Sales Data Analysis

## 📊 Project Overview

This project focuses on cleaning, analyzing, and visualizing sales data using Power BI.

The project was completed using Power Query for data cleaning, Power BI for visualization, and DAX for calculations.

The main objective was to prepare the dataset for analysis and create meaningful visualizations to understand sales, products, regions, and profit trends.

---

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV
- GitHub
